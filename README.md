# Локальный аудит безопасности LLM: Тестирование на уязвимости Prompt Injection (Garak + Ollama)

Практический проект по анализу защищенности больших языковых моделей (LLM) от логических атак класса Jailbreak и интеграция результатов со стандартами индустрии (OWASP Top 10 for LLM).

## 🚀 Архитектура стенда (Полный локальный запуск)
В отличие от облачных тестов, данный стенд развернут полностью локально без затрат на платные API, что гарантирует приватность данных и безопасность проведения агрессивных атак.

*   **Host OS:** Windows 11 (Оптимизация: сделан андервольт GPU, используется охлаждающая подставка для удержания стабильных 69°C под пиковой ИИ-нагрузкой).
*   **Hardware:** Ноутбук с дискретной видеокартой NVIDIA RTX 5050 Laptop (утилизация тензорных ядер при генерации токенов составила 90%).
*   **ИИ-Движок:** Ollama v0.x (Локальный API-сервер на порту `11434`).
*   **Тестируемая модель:** `Llama-3.2 (3B)` от Meta.
*   **Инструмент Red Teaming:** Nvidia Garak v0.17.1 (Автоматизированный сканер уязвимостей LLM).

## 🛠️ Пошаговое развертывание (Setup & Run)

### 1. Подготовка окружения Python
Для изоляции хакерского инструментария развернуто чистое виртуальное окружение:
```bash
cd path/to/garak-main
python -m venv venv
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2. Запуск целевой модели
Модель запущена локально на тензорных ядрах видеокарты через Ollama:
```bash
ollama run llama3.2
```

### 3. Проведение автоматизированной атаки
Запуск таргетированного сканирования против логики модели с использованием актуального синтаксиса Garak (вектор атак класса DAN — Do Anything Now):
```bash
python -m garak --target_type ollama --target_name llama3.2 --spec probes.dan
```

## 🔍 Сопоставление со стандартом OWASP Top 10 for LLM

Выявленные в ходе автоматического аудита уязвимости напрямую соотносятся с ключевыми угрозами индустрии:
1.  **LLM01: Prompt Injection (Внедрение промтов):** Подтверждено тестом `DanInTheWild` (69.14% успеха). Модель принимает инструкции атакующего за легитимный системный контекст.
2.  **LLM02: Insecure Output Handling (Небезопасная обработка вывода):** Успешные атаки `dan.DAN` (84.41%) доказывают, что модель генерирует потенциально опасный контент, который никак не фильтруется на выходе.
3.  **LLM06: Sensitive Information Disclosure (Разглашение данных):** Высокий процент обхода встроенных заглушек (`MitigationBypass` — 75.59%) открывает вектор для извлечения системных промтов модели.
